Compare keyword, vector, and hybrid retrieval on 12 labeled development questions using the 40-ticket synthetic sample. Load the sample before running. These examples were used during development; this is not a held-out benchmark.

Precision@3: relevant tickets among the first three. Recall@5: labeled relevant tickets found in the first five. MRR@5: how early the first relevant ticket appears. This measures retrieval, not response accuracy.
